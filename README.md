# Электрики Димка и Вадимка — Одностраничный сайт-визитка

Юмористический одностраничный сайт-визитка для бригады электриков по дачам, гаражам и безнадёжным объектам.

## Состав проекта
- `index.html` — основная страница с SEO-разметкой (Open Graph, Schema.org `Electrician`), прайсом с оплатой натурой, портфолио и отзывами.
- `style.css` — адаптивные стили.
- `robots.txt` и `sitemap.xml` — файлы индексации для поисковых систем.
- `images/` — фото Димки и фото выполненных работ.
